# Mutandis

This item is used to mutate plants into other, random plants. This is the only way to obtain certain Witchery plants, like [Rowan Saplings](/World/Plants/Trees/Rowan%20Sapling.md), Alder Saplings, and Hawthorn Saplings.

Mutandis can be upgraded into [Mutandis Extremis](Mutandis%20Extremis.md).
### Book Entry
"A concoction of evil scrambled eggs. Use it on plants to mutate them into other varieties. For a short time after use, Mutandis will only affect the same type of plant, allowing repeated use to cycle through its possible mutations. For example, repeatedly using it on a sapling will eventually transform it into different kinds of saplings."
