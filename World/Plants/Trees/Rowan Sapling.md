# Rowan Sapling

It grows into the Rowan Tree, which can be harvested for Rowan Wood and Rowan Leaves. Rowan Leaves can drop Rowan Berries, and more saplings. Rowan Saplings can be used to create Wood Ash and Whiff of Magic in a Witches Oven.

Rowan Saplings can only be obtained by using [Mutandis](/Items/Resources/Mutandis.md) on another plant. The chance that it is produced is random.

Breaking Rowan Wood can result in the spawning of an Ent.
